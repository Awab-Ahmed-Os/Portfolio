# Awab Ahmed - Portfolio Website

A responsive, single-page personal portfolio built from scratch with vanilla HTML, CSS, and JavaScript. It presents my cybersecurity and IT background, projects, skills, and verified certifications in one place.

Live site: https://awab-ahmed-os.github.io/Portfolio/

---

## About

I am an entry-level cybersecurity and IT professional with a BSc (Hons) in Information Technology and the Google Cybersecurity Professional Certificate. This website is my online CV: it shows what I have built and what I know, and it lets visitors view and download my certifications.

## Features

- Fully responsive design that works on phones, tablets, and desktops
- Single-page layout with smooth navigation between sections
- Mobile-friendly navigation menu
- Animated UI elements
- Dynamic certification gallery with PDF download support
- No frameworks or libraries, only HTML, CSS, and vanilla JavaScript, which keeps it fast and lightweight

## Run Locally

No build tools or installation are needed.

```bash
git clone https://github.com/AwabAhmed-Os/Portfolio.git
cd Portfolio
```

Then open `index.html` in your browser.

For live reloading, use the VS Code Live Server extension, or run a simple local server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Deployment

The site is hosted for free on GitHub Pages:

1. Push the project to a GitHub repository.
2. Go to Settings > Pages.
3. Under Source, choose the main branch and the root folder.
4. Save. The site will be available at https://USERNAME.github.io/REPOSITORY/

## Use It as a Template

1. Edit the text and links in `index.html`.
2. Replace the images with your own.
3. Add your own certificate PDFs and update the gallery list in the JavaScript file.
4. Change the colors and fonts in the CSS file.
